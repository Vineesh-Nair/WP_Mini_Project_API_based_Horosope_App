# WP Mini Project: API-based Horoscope App

* **Aarya Mhatre** (Team Lead)

A lightweight web application that fetches and displays horoscope data using an external API and local JSON storage.

## 🚀 Features
* **Real-time Data:** Fetches daily horoscopes via API.
* **Minimal Storage:** Uses `data.json` for lightweight data management.
* **Responsive UI:** Built with HTML, CSS, and JavaScript.
* **Node.js Backend:** Express server handling API requests.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend:** Node.js, Express.js
* **Storage:** JSON
